# Limpio Perú Frontend

Panel web para registrar y gestionar reportes ambientales. La interfaz adapta sus herramientas a tres roles: Ciudadano, Operador y Administrador.

## Desarrollo

```bash
npm install
npm run dev
```

El frontend usa `http://127.0.0.1:8000` como API por defecto. Para cambiarla:

```env
VITE_API_URL=https://api.ejemplo.com
```

## Verificación

```bash
npm run lint
npm run build
```
